"Bait" — one word for the whole internet, entered in the make.fun bounty
`u-ronigrv-the-internet-in-one-word-e388f33b` ("The Internet in One Word").

> Bait

The word is 4 characters. Everything online is engineered to hook
attention — clickbait, rage bait, engagement bait — so the whole
internet is bait: funny on its own, true of every corner of it rather
than one app or mood, and complete in a single beat.

## The program

`main.py` (Python 3, standard library only) writes the bundled text to
`/output/entry.txt`, checking it first: UTF-8, 1 to 30 characters,
exactly one word of letters, not only whitespace. It uses no network,
and every run writes identical bytes.

## Run it

```sh
python3 main.py /tmp/entry.txt
```
